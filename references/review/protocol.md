# 冷读与对比盲审执行协议

本附件落实写作指南G37–G44。内部核验、冷读和对比盲审分开执行；不能把带修改答案的回归核验称为盲审。

## 1. 先固定输入

记录本稿版本、核心参考名单、同会议近两年获奖论文池及来源。核对年份/届次和材料完整性，不用某个项目曾有的篇数代替“全部”。随机样本保存实际抽样结果；不得为了好看、出场次数或胜负手选后声称简单随机。记录池、抽样方法和实际名单；数量不足就说明，不捏造或擅换范围。

核对实际送入的文字、公式、图表、图注和必要引用。匿名化不能破坏论证内容。删除作者、单位、发表状态、奖项和来源映射；映射只留在评审看不到的位置。PDF抽取损坏时换保真输入，不据乱码修改论文。入口审查只能对入口的职责下判断，不能要求摘要装下全文。

完整对照独立原稿的实际内容，不能用同一抽取结果自比、同一常量生成和自检、或只看首尾字符就称完整。材料损坏的执行体结果不用于放行、胜负和改稿裁决；有授权才用干净材料新执行体重做，否则如实标未验证。

## 2. 确认真正隔离

评审是新的独立执行体，只收到指定匿名材料和固定中立任务。不得读取项目文件、作者裁定、技能规则、记忆、历史评语、主会话结论、期望优势或联网补材料。内部审计可以读这些依据，盲审不可以。

检查实际工具和上下文配置。若工具仍可访问源项目，只有提示词写“不要读”而没有验证隔离，就如实记录“指令隔离，未验证访问隔离”，不能声称完成了严格盲审。不要为了隔离关闭管理策略或绕过权限。

分别核对运行环境与最终实际发送提示。关闭工具的探针不能证明提示未夹带作者答案、偏好文档、历史评语或旧裁定；指定会议偏好另作R25诊断，不混入中立盲审。记录实际展开输入及探针与正式参数是否一致。

## 3. 顺序冷读

使用未参与改稿、未读过完整稿或旧卡点的新读者。先只给标题与摘要，随后按读者顺序逐章增加。不要提前提供后文或解释卡点。同一个冷读执行体可保留它自己先前的理解；报告数随阅读阶段确定，不固定为某个章数。

固定问题：

1. 用平实的自己的话说出目前认为研究解决什么、发现什么、为什么重要。不能只把原术语重新串起来。
2. 引用没读懂的原句，说出卡在哪里、目前猜测和不确定之处。
3. 哪些疑问阻碍当前理解，哪些合理地预期后文回答？
4. 本章是否解决之前的疑问？现在的主线是什么？

最后核对完整复述、一直未解决的关键卡点及错误推断。需要独立理解的重点框可单独冷读。模型流利复述不等于人能读懂。

目录、入口、正文自足等可共用严格递增的真实阶段记录，分别给判断。先封存阶段输入和读法，再给后续材料。读过答案的执行体可以知情核验，但修改后的首次阅读须另用新读者。

## 4. 三级对比

同一轮固定本稿版本、问题和材料范围。先与已确定的核心参考论文对比，通过后随机抽六篇同会议近两年获奖论文，再通过后覆盖同范围全部获奖论文。每组做正反呈现顺序，双方获得相同条件。前一级已暴露有依据的问题时，停止扩大，先处理。

中立任务示例（正文语言按稿件，汇总按作者约定）：

> 比较下面匿名论文A和B，按给定阅读范围判断。分别复述各自新增的认识及其证据，指出各自最有价值的长处、重要缺点，以及你更愿意推荐或继续阅读哪篇和理由。每条缺点、每条决定选择的理由都须引用对应论文原文及位置，并保留足以支撑判断的上下文。说清哪里没理解、哪里不相信以及原因。不得根据作者、发表状态或外部资料判断；缺少信息就说明，不能补写材料中不存在的内容。

这只是问题框架，不能把作者希望赢的理由塞进去。对摘要等局部材料注明范围，不能由未提供正文推出全文缺证据。

## 5. 收到结果后

逐条保留来源和出处，合并同义意见但不丢独有内容。每条都分析；非实质、已裁定、范围外、偏好等不能成为免检标签。引文真实不等于批评成立。核对引文是否支持批评、上下文是否已回答；区分论文错误、表达误读、评审自身错误及不同标准。不得用“评审说了”作为改稿理由。

处理记录只需能回答：原文、评审读法、原意、独立依据、改/不改及理由、改法和复核。反复误读查具体文字和结构；不能一味怪评审，也不能一味补解释。向作者汇报以作品长处及变化为主，完整意见与处置可附在工作材料中。

比较改效时保持对手、输入、问题、模型和呈现规程可比；条件不同须标限制，没有有效旧读者证据只能判断当前表现，不能把差异直接归因于改稿。列出消除、新增和加重的读法。先确认修复实际留在当前版本，且没有被下一批删回。胜场和分数不能替代这些判断；不能为噪声重写本来清楚的段落。

## 6. 转阶段和停止

通过依据是成立问题已处理、主线正确理解、反复误读已查根因及剩余不采纳理由充分，不是全胜或没有任何负面评价。完整三级期间发生实质修改或主线误读修复，内部审计通过后从第一级重新推进。

定稿期按作者明确安排可以定点复测此前问题严重的场次。作者停止新盲审，就不再新增；已有结果仍完整分析，并处理已授权且有独立依据的问题。模型有依据判断实质性问题已收敛时，可以停止本轮工作，交回当前完整稿、判断依据与检查覆盖；未跑的场次和未核验范围如实列出，不声称已全量通过。最后的润色优化由人工介入决定；停用提醒，等待作者明确安排，不为措辞偏好不断加轮次。
