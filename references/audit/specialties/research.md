# 研究证据专项卡

先按[执行安排](../routing.md)选择当前单元和影响范围，再读取[checks.json](../checks.json)所列S项。检查点可以联合，但各项结论不互相抵消；本文件不要求每轮全量。

<a id="r01"></a>

## R01 来源与主张核验

类型：专项审计。覆盖：S01, S02, S13。

目标：原始来源究竟记录了什么，稿件把它写成了什么，以及关键数值被赋予了什么身份；逐条核定事实、引用支撑和数值身份。

组织理由：三项同读原始来源和稿件主张，联合可完成来源→作者处理→具体主张的整条核验。若只分开读，会重复取证，且容易让S01确认来源真实、S02确认引用存在、S13确认数值来历后却漏掉三者间的归属偷换。合并收益是共同判来源实际支持的内容，不是三项都与事实有关。保留三个独立分项结果；不扩张成笼统事实与推理。

### 输入

1. 事实句及关键数字位置
2. 最早原记录、原数据与处理日志
3. 稿件/图表前后版本
4. 数值选择或推导过程
5. 带完整上下文的引用句
6. 被引原文相关段、表、脚注与版本
7. 引用增删移动差异

### 执行

1. 逐条拆为主体、时间、行为、来源；区分计划、发生与观察。
2. 沿来源链辨别原数据、作者加工与外部评价，核对与用户口述矛盾。
3. 为关键数字标记观察、计算、理论或示意身份；替换合法示意数字检验论证职责。
4. 核正文、标题、图注语法有无把示意或作者处理写成实测或外部结论；返回所有同源位置。
5. 拆最小主张，逐项对照主体、对象、条件、时序。
6. 写清来源支持部分与本稿推断部分，主动找同源反证。
7. 删移后核剩余重要主张是否悬空；保留准确且有力的引文。

### 分项回包

1. {'S01': '事实账、原记录、主体/时间/行为、冲突与处置。', 'S13': '数字来源与身份、换数检验、解释价值及必要条件；不把数算对当身份正确。', 'S02': '主张→原文定位→支持范围→本稿桥接推理→反例。'}

## R02 前提、数学证明与理论依赖

类型：专项审计。覆盖：S03, S04, S05。

目标：现实现象、作者定义和建模选择如何形成形式前提；这些前提是否足以且有必要地推出稿件声称的命题；删移后支撑是否仍在。

组织理由：S03必须知道证明实际使用什么条件，S04必须知道前提代表什么对象，S05必须知道哪些条件与步骤可以删除。共享定义—前提—证明—结论链能共同发现‘形式证明正确但前提身份误写’和‘删去的是多余表述还是必要条件’。分阶段联合比三次重建同一链更利于裁决。数学证明仍是一项实质、独立完成的判断，不能以身份表或依赖图替代推导。

### 输入

1. 全部定义、假设和能力描述
2. 事实原证据
3. 结论实际依赖条件及对象边界
4. 当前定义、引理、定理、证明和附录全链
5. 理论改前后差异与被删材料
6. 正文、摘要和图中对命题的解释
7. 变量域、量词和边界

### 执行

1. 阶段一：核前提原始事实依据，标记事实、定义、建模选择或待证命题；先不因形式上可推就承认现实前提。
2. 阶段二：从当前定义独立重推全部受影响命题，检查条件必要性、量词、域、边界及正文解释；反例与推导单独留证。
3. 阶段三：回看身份和证明的交叉约束，核事实是否被误列额外假设、真正选择是否冒充事实；允许发现需要修正前提身份或命题范围。
4. 阶段四：按删后实际文本重建结论依赖，分别判断删符号、估计、例子、引理与移附录的效果。

### 分项回包

1. {'S03': '前提身份表、依据、必要性、改前后适用对象变化。', 'S04': '可复算推导、反例、缺失条件、命题解释等价性。', 'S05': '贡献→理论依赖表、删改对象类型、删后可推出/不可推出、最小修复。'}

## R03 机制归类与定义有效性

类型：专项审计。覆盖：S06。

目标：定义是否真的对应研究机制，是否按实际决策流程归类，是否通过定义预先选入结论。

组织理由：此任务裁决判据本身与真实机制的匹配。S07是在给定有效判据下编码；两者共享材料但不能用编码一致率证明判据有效。保留独立机制专项。

### 输入

1. 对象定义、纳入规则和分类表
2. 真实机制原文、代码或流程
3. 定理对象依赖和合理反例

### 执行

1. 先记录读什么、凭什么决定、目标是什么，再据机制判据分类。
2. 区分名称、目标与实际机制；用边界反例检验循环定义。
3. 核正文、样本、案例、表和贡献是否采用同一有效判据。

### 分项回包

1. {'S06': '机制事实卡、原文定位、判据有效性、归类理由、反例和受影响对象。'}

## R04 编码、纳入与统计

类型：专项审计。覆盖：S07, S08。

目标：从原始记录到可分析样本再到统计结论的整条链是否正确。

组织理由：同一记录的配置、去重单位与纳入资格直接决定分母。联合审计可在看见百分比差异时回到原文裁决，而非在两路间把错误编码当已知事实传递。保留独立重判与独立复算两个动作和分项结论；联合不等于把确认标签直接相加。

### 输入

1. 来源原文、未经旧标签提示的逐条记录
2. 当前编码规则、版本与评测配置
3. 抽样及停止日志、种子
4. 原计算脚本、全部数字位置及统计单位

### 执行

1. 先从原文按现行判据独立重判，不看旧标签；记录排除、配置差异、重复主张与争议。
2. 另从同一版本原记录建立计数和统计单位，不以旧表、旧脚本输出或刚给出的编码总PASS作输入保证。
3. 对分类和去重争议返回原文，保留不同合理口径的敏感性结果，不用强行一致制造通过。
4. 明确分子分母、排除规则、估计对象；复核抽样日志与停止规则。
5. 核数字更新如何改变实质结论并追踪全部正文、图、表、摘要和附件。

### 分项回包

1. {'S07': '逐条判定、原文、纳入/去重/配置理由、与旧码差异及未决争议。', 'S08': '独立计数与计算过程、分子分母和分析单位、抽样核验、敏感性、所有数字差异。'}

## R05 证据强度与结论外推

类型：专项审计。覆盖：S09。

目标：主张的存在/普遍、可能/必然、优于/最优和范围是否恰好匹配证据。

组织理由：它跨越定理、样本、来源和叙述来裁决最大可支持主张，不等于数学有效性或一般论证连贯。保留独立专项，并与散文量词读法共享句子而不互代。

### 输入

1. 最强主张及限定词
2. 原始证据范围与样本定义
3. 形式定理及条件
4. 反例和实验目的

### 执行

1. 把关键主张写成逻辑形式，反向找证据为真而主张为假的场景。
2. 区分未报告/未发生、能力/必然行为、样本/总体。
3. 保留证据足以支持的强度，不机械降调；核入口、图表和正文同一主张。

### 分项回包

1. {'S09': '逻辑形式、证据范围、反例、最大可支持强度与修句。'}

## R06 实验问题与设计鉴别力

类型：专项审计。覆盖：S10。

目标：实验可能出现的结果能否区分论文主张与替代解释，实际执行是否确实测试原问题。

组织理由：设计有效性属于研究问题和因果/鉴别结构。与S11共用候选材料，但有效实验未必值得进入论文，不能让实验设计者自己以有效为由判有价值。

### 输入

1. 目标主张和替代解释
2. 干预、对照、指标、输入、配置与运行环境
3. 开源实现与真实运行记录

### 执行

1. 先列可能结果及其改变的结论。
2. 构造主张不成立的反事实，核实验有无鉴别力。
3. 核测量对象、混杂、真实实现和默认配置，区分存在性、效应量与覆盖范围。
4. 运行后由原记录核真正测试问题；无鉴别力则改设计或取消。

### 分项回包

1. {'S10': '主张—可能结果—可推结论、混杂、可执行设计及实际执行偏离。'}

## R07 材料取舍与论证职责

类型：专项审计。覆盖：S11, S52。

目标：某材料加入、保留、删除或移动后，目标读者能否获得有意义的新判断或更可信的证据，收益是否抵过负担和风险。；保留读者判断论点所需的方法与证据，移除只证明执行过程的记录。

组织理由：材料增益与工程冗余需要共同回答删掉它会失去什么判断依据。分别核学术增益、必要方法及呈现职责，避免一方因真实而保留全部日志、另一方为简洁删掉必要方法。

### 输入

1. 当前研究主张、已有长处和实际读者疑问
2. 现有与候选材料及原证据
3. 各材料职责、现有正文/附录位置
4. 设计可能结果及真实结果
5. 正文、附录、表注脚注；方法、来源与材料包；逐处实际论证用途

### 执行

1. 逐项说明没有它缺什么，有它新增什么读者判断。
2. 对照现有定理、案例、数据，判断重复、可信度、替代解释和边界说明。
3. 比较解释负担、新质疑、弱证据连带风险；不把主结论不变单独当否决理由。
4. 作保留/删除/重写/回搬决定；有价值正常承担职责，无价值不藏入附录。
5. 逐句问删除后读者失去哪个论断的何种判断依据，区分必要方法与执行记录。
6. 不给可复现/可追溯自动保留权，也不按关键词一刀切删除。
7. 列位置短引、论证/工程职责、删除损失、保留/迁移/删除依据。
8. 删移后核方法、条件、来源仍完整；与 S11 分别回包后统一裁决。

### 分项回包

1. S11：材料承载的学术判断、证据增量及保留/删减理由。
2. S52：必要方法与工程日志的边界，删除或压缩后的职责承接及复核。

## R08 平凡推理与新知识增量

类型：专项审计。覆盖：S12。

目标：研究单元是否给目标读者带来此前不能直接得到的新认识，显然推理是在必要搭桥还是冒充发现。

组织理由：用户明确不能被数学、逻辑、易读性或贡献呈现替代。此任务必须重建读者之前已知什么，再从研究证据提取有分量的新后果；证明正确、说得通、读得懂都不能完成这件事。

### 输入

1. 当前稿件尤其摘要末句、贡献、定理解释、实验结论
2. 目标读者前置知识及此前已呈现信息
3. 原始研究证据与可支持后果

### 执行

1. 明确本单元应新增的判断。
2. 做前文可推性与不看本研究可推性检验。
3. 区分必要桥梁和包装成结果的常识，保留必要桥梁。
4. 从已有证据提取最有分量的非显然后果，重组表达；不编造发现或夸大适用范围。

### 分项回包

1. {'S12': '已有知识→本句增量→目标判断→证据→改写；保留必要桥梁的理由。'}
