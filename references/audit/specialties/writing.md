## R09 图表真实性、解读与可达性

类型：专项审计。覆盖：S14, S48, S49。

目标：最终渲染图表中的事实、顺序、角色、计数单位和关系是否对应真实方法及记录。；读者能正确解释图表，且正文在需要图表信息的位置有可达的依据。

组织理由：图表的实际读法、真实内容和引用位置共同决定使用效果，可分阶段共用输入。真实性、可理解性、可达性分别报告，不互相抵消。

### 输入

1. 最终渲染图表和源图
2. 正文方法
3. 真实筛选、编码、抽样、审核记录
4. 各阶段数字和单位
5. 先仅实际渲染图表及自身题注、图例；封存后给数据定义、对应正文和完整 PDF 页序

### 执行

1. 第一阶段只给实际图表、图题、图例，先封存新读者的逐图理解、卡点和歧义；需要检验引用处阻断时，先按实际页面顺序记录该处需要什么及能否取得。
2. 封存首读后，再给原始数据、真实流程记录和正文，逐节点、箭头、数字、图例核对真假与含义。图文一致不等于二者都真实。
3. 逐引用核当前句需要图中什么信息、当前位置是否已提供，而非只计页距；打开最终渲染核尺寸、裁切与可读性。
4. 修改后的图若需验证首次读法，另用未见答案的新读者；原审计者只能继续做知情的真值和位置核对。

### 分项回包

1. S14：原始数据/流程与图中事实的逐项对应及真实渲染结果。
2. S48：封存的图表首读、歧义与卡点，以及修改后的新读者检查范围。
3. S49：正文引用处的信息需要、实际位置和可达性判断。

## R10 全篇、章节论证与变更依赖

类型：专项审计。覆盖：S15, S16, S17, S44, S60, S61, S62, S63, S64。

目标：读者可沿论文现存文字，从同一个主问题走到受证据支持的主结论。；目录给出正确任务预期，章首说明承接与目标，小节实际完成总分或递进关系。；结构、裁定与改动合理性联合审计

组织理由：全篇主问题、章职责、标题及删改依赖共同使用一张论证关系图。先判断新版自身，再查旧裁定和全部差异，可避免重复重建论证及彼此冲突的局部重排。各检查点仍分别记录结果。

### 输入

1. 冻结完整稿、真实页序及图表；先不给旧评语
2. 先仅完整目录（全部层级及附录标题），封存预期后才给各章、上下章连接
3. 有效基线至当前全部diff、新旧框架、裁定原理由、完整稿和附录、删除前文本

### 执行

1. 先提供当前目标、范围与明确限制；先单读目录并封存预期，再按新版正文重建问题、已有前提、证据、新判断与下章用途。旧方案和旧通过结论此时不提供。
2. 区分原文明说、此前信息直接可推、审计者补写；核主问题是否偷换，章内总分或递进是否实际成立，章首与标题是否说明并兑现职责。
3. 封存新版判断后，再核旧稿、全部本批及应纳入的跨批diff、旧裁定与前提。旧裁定真实也可能失效，不能以旧架构为名删除仍有价值内容。
4. 对删、移、恢复核谁承担原职责；按旧对象、名称和接口扫描关联残留，不只检查改动行。完整核对本批变更集合。
5. 普通修订只重建受影响的论证链；分别列本次重建、证据仍有效可复用的链及已核的全部变更。定义、核心主张或跨章依赖改变时扩大覆盖。

### 分项回包

1. 各S分项证据、关键两端定位、作者内容与既有优势的保留、删除功能损失、需要D01二验的具体裁决

## R11 句段内容逻辑与论证推进

类型：专项审计。覆盖：S18, S19, S20, S22, S31。

目标：逐句核当前位置的问题与实际回答是否匹配、证据是否支持观点、推理关系是否成立且写在文中。PEAL是功能检查，标签齐全不能代替内容逻辑。

组织理由：分析不足、主题偏移、冗余、长段、空排比必须同看上下文：删除一句可能同时删分析，拆段可能切断推理。合并阅读，但保留五个检查结果，不按句式各读全文。 作者指定本专项为最高优先级，实际审计、实质裁决二验及必要的内容逻辑复验使用当前可调用的最高价格档推理模型；型号与价格核实、显式选择、回执及禁止静默降级按routing执行。

### 输入

1. 完整相关章节、段落与相邻段、原证据；全文重复候选索引和渲染页

### 执行

1. 先依据上下文确定当前位置的问题和段落职责，再引用每句实际回答、提供的证据和得到的判断。先查内容关系，再查PEAL功能，不从标签反推正确。
2. S20逐句对照“此处问什么—原句答什么”，核答非所问、真实但无关的材料、缺直接推理一步及绕远解释。区分原文明说、此前材料足以推出、审查者自己补写；审查者补出的桥梁不算原稿通过。
3. S18核观点、证据、分析与衔接的实际关系；定义、方法、证明按职责判断适用，不凑四句。涉及来源支撑交S02，指代错接交S27，跨章依赖交R10，复用原文证据而非各自重复全审。
4. S19追踪重复命题在每处的职责；S22按独立话题和论证步判拆分；S31核并列项新增信息。删句、拆段不能损坏必要推理。
5. 查错位根因，将异位材料归位、删除无用内容或补出有依据的直接关系；不给正确事实硬接“因此”。给完整候选段及邻段衔接，经过D01后验证读者仅用此前上下文能否得到正确判断。

### 分项回包

1. S20内容逻辑：位置问题、原句实际回答、证据与判断关系、具体断点及依据；未发现问题时提供关键关系的覆盖证据。
2. S18 PEAL及S19/S22/S31分别给结果，不能用PEAL通过或总PASS代替内容逻辑。
3. 共同给完整候选或不改理由、原长处及必要条件保留、独立二验和改后阅读验证范围。
4. 模型选择依据、实际指定型号、实际返回型号及可核实状态；无法满足最高价格档要求时报告限制与未执行/待核实，不能报通过。

## R12 直接句意、语义边界与表达

类型：专项审计。覆盖：S21, S27, S28, S29, S30, S32, S33, S34, S37。

目标：用直接的主谓动作表达准确判断，去掉妨碍理解的修辞，同时保护必要范围、真实对照和有证据的强结论。

组织理由：限定词、歧义、绝对语气、防御、二分、对比和隐喻会在同一句相互制约，必须联合改写，不能一项删词、下一项机械恢复。S37 为语体判断提供真实同职责对照。各检查点有独立证据和裁决，不能只报语言流畅。

### 输入

1. 目标读者知识、全文真实上下文；回归为改动句及语义闭包；正式定义、证据范围、同功能真实范本原文

### 执行

1. S21 写原句→普通意思→直接论文句，核主语、动作、对象、要点位置。
2. S27 列合理先行词及两种读法；S28 逐位置做删限定的真值/范围/对象反例；S34 比较首读范围与正式量词、样本范围。
3. S29 将免责句改为正面事实且保留必要条件；S30 检查互斥、穷尽、共存反例；S32 分真实反差、定位差异、惯性衬托。
4. S33 把隐喻译成字面义，以真实领域语料判断适用；S37 引同职责原句并解释借鉴或保留差异的理由。
5. 每个检查点返回命中位置、两端语义、删留依据和完整替换句；不得凭词数、形式比例或模型复述流利判通过。

### 分项回包

1. 逐个已执行S项给判断及原文/证据；共同给已有长处、具体修法或不改理由、覆盖与未查范围。不能只给总PASS。

## R13 概念、术语与符号

类型：专项审计。覆盖：S23, S24, S25, S26, S36。

目标：必要概念保持精度和稳定对象映射，读者在首次需要时可懂，记忆与重复负担可接受。

组织理由：必要性、一致性、首用、符号替意和密度必须联合判断。删术语可能产生长描述，压密度可能造同义词，统一名称可能合并对象，符号转文字可能损精度；分拆代理各优化一指标会互相回退。

### 输入

1. 全文、附录、图表框、脚注真实阅读顺序；定义与证明用途；领域常用词及可比语料；概念—对象双向表

### 执行

1. S23 盘点新词与特殊通用词，列白话义、首用、后用、推理用途；决定保留、改现成术语或直述。
2. S24 建对象→名称和名称→对象双向映射，逐处核所指，保护真实区别。
3. S25 建首用—首个可理解说明表，只按此前材料和读者预备知识判断。
4. S26 遮符号读散文与结论格，分推导必要记号与替代关键意思的符号。
5. S36 同口径统计词与短语密度，仅定位；逐处判简称/直述/保留，核指代和精度。
6. 联合比较候选方案对五项的影响，分别回包，不允许用命名数量或频率达标代替读者结果。

### 分项回包

1. 逐个已执行S项给判断及原文/证据；共同给已有长处、具体修法或不改理由、覆盖与未查范围。不能只给总PASS。

## R14 贡献归属与价值呈现

类型：专项审计。覆盖：S35, S43, S45。

目标：让已证实的新工作和价值实际被看见，同时不把局部失败或缺全域保证写成完全无用。

组织理由：贡献条目、成功/失败边界及叙事重心共同影响读者价值判断，需一起权衡。与 S12 的知识增量、S01/S02 的事实归属保持不同结论：真实贡献可以被写弱，写得突出也不能证明新颖。

### 输入

1. 全文入口、贡献及各节发现；本文新工作与既有组件来源；真实成功失败证据；基线

### 执行

1. 先列能改变读者判断的已有长处和证据。
2. S35 分实际改善、缺证据、局部失败、全域保证，核不现实极端条件是否支配叙事。
3. S43 逐贡献列交付、新增认知、价值、归属、正文证据，区分发明、适用性发现、证明、系统化。
4. S45 追踪强点在标题摘要引言贡献节首结论的承载位置，区分研究发现与工作过程。
5. 交贡献—证据表、成功/失败读法、价值承载图及完整候选；不掩反证、不以话术补新颖性。

### 分项回包

1. 逐个已执行S项给判断及原文/证据；共同给已有长处、具体修法或不改理由、覆盖与未查范围。不能只给总PASS。

## R15 标题、摘要与引言入口

类型：专项审计。覆盖：S40, S41, S42。

目标：仅凭当前入口层级，读者形成准确的研究预期，理解问题、发现和价值，并愿意继续读。

组织理由：标题承诺、摘要脱文论证、引言速度与层次属于同一逐层入口；可递增输入联合采集，但三项输出分别存在，不以总体印象抵消任一失败。

### 输入

1. 阶段一仅主标题；阶段二仅追加摘要；阶段三仅追加引言及引言实际图表；先不提供正文、作者解释、标准答案或旧评语

### 执行

1. S40 单读标题，封存问题、对象、主张及价值预期。
2. S41 加摘要，逐句列问题/缺口/工作/发现/价值职责和关系，平白复述，记录数字方向、因果桥、末句产出及卡点；封存。
3. S42 加引言，逐段列入口职责、范围、价值和机制过载；区分入口必需与正文细节；封存。
4. 以上首读阶段完成后才可给全文作兑现、归属、证据和保长处核对；若共用 R16 的读者，则必须等所有正文章节和 S50 记录封存后才解禁。
5. 分别交标题承诺表、摘要逐句职责表、引言段职责与移位方案。

### 分项回包

1. 逐个已执行S项给判断及原文/证据；共同给已有长处、具体修法或不改理由、覆盖与未查范围。不能只给总PASS。

## R16 逐章阅读与正文自足

类型：专项审计。覆盖：S38, S50。

目标：目标读者按实际顺序能理解句意、因果和主线，且无需附录才能判断核心主张。

组织理由：S38 的连续读者状态与 S50 的正文无附录条件天然兼容，可一次递增阅读分别留证。整体逻辑专项不能替代真实理解；S50 也不能只由交叉引用检查替代。

### 输入

1. 经过保真核对的冻结标题摘要、按实际顺序的正文章节和当场可见图表；主文读完前不给附录或任何答案

### 执行

1. 可接续 R15 的合规首读，不重复阅读相同入口；按真实顺序逐章追加，每章记录封存后才发下一章。
2. 每阶段保存输入范围、平白复述、依据、卡点原句、猜测与确定性、阻断/可后置疑问、旧疑问是否回答、当前主线。
3. 正文结束封存完整复述和未解项；S50 单列核心主张缺少的定义/前提/理由/边界，区分可延后技术细节。
4. 全部封存后才提供附录，逐缺口对账，给必须回搬与可后置内容及理由。
5. 原始记录全交回，再独立核真实缺陷、知识缺口和事实问题；不以复读术语当理解。

### 分项回包

1. 逐个已执行S项给判断及原文/证据；共同给已有长处、具体修法或不改理由、覆盖与未查范围。不能只给总PASS。

## R17 修改回归、长处保护与改效

类型：专项审计。覆盖：S39, S51, S71。

目标：这批改动在读者端实际改善理解，同时没有丢失原有定位、发现、证据和论证职责。

组织理由：新版首读、职责保留和可比改效都围绕同一批真实变化，按新读法→diff→旧读者记录顺序联合核验，避免三个角色重复读相同材料。无可比证据时不得声称已经证明改善。

### 输入

1. 第一阶段仅新版改动处及真实此前上下文；第二阶段才给基线、完整 diff、旧卡点、跨章依赖与长处证据

### 执行

1. 由未参与内审或修改的新读者，先只读新版相关位置及此前必要上下文，封存实际理解与卡点，不先给旧问题和预期答案。
2. 随后看基线diff，核本批新增/退化、旧问题未解、必要条件与原长处是否仍有人承担；原修复是否被后续批次覆盖。
3. 有可比旧读者证据时，逐条比较新增、消失、加重、减轻与未变的读法和长处，列提示、模型、材料与对手差异。
4. 没有有效基线时只判当前表现与职责保留，S71标前后改效证据不足。不能让已读新版的同一人倒读旧稿制造独立基线。
5. 再次修改后，知情审查者可查实现；要声称首次读法改善须用新读者。需要新比较评审时遵守当前授权，不自动新增盲审。

### 分项回包

1. 逐个已执行S项给判断及原文/证据；共同给已有长处、具体修法或不改理由、覆盖与未查范围。不能只给总PASS。

## R18 重点框的必要性、独立读法与增量

类型：专项审计。覆盖：S46, S47。

目标：先判断论文是否需要重点框以及每个候选框的净收益；决定使用后，再核类别职责、真实内容与独立读法。可以不用框，不预设三种或固定数量。

组织理由：必要性与读者效果联合判断，但不得让已知正文或候选理由污染首次读框。调度者先判适用性，另给新读者有限输入。

### 输入

1. 适用性判断者读取论文目标、正文承载位置、版面与会议要求、现有或拟议框；不能因范本有框就要求本稿有框。
2. 仅对决定保留或试拟的框启动新读者；首读只给框及自身标题，封存后才给正文、证据、其他框和设置理由。

### 执行

1. S46先比较不用框、融入正文或图表、使用框三种呈现的读者收益与篇幅/重复/打断成本。允许整篇零框，不凑类别和数量；没有具体候选收益时不为审计造框。
2. 确有净收益才按本稿内容选择类别与数量。Takeaway、Key Finding、Research Gap等是可选例子，不是三件套；内容真实且值得强调即可，不能强造反直觉。无框且无提出理由时记录S46无对应对象、S47不适用，结束本专项。
3. S47由新读者逐框封存平白复述、卡点、猜测和实际所得判断；不提前给正文或期待答案。决定是否需要框的人不能冒充这个新读者。
4. 封存后回正文核判断—证据—必要条件，比较框间及与正文的职责是否重复；没有必要性就删或回正文，不以改写一个框完成任务。
5. 分别给使用必要性、内容有效性、独立可懂及留/删/移/改的判断；修改后的首读换新读者。定理、算法、定义和案例环境按各自职责，不套用洞见框的形式。

### 分项回包

1. S46：有框/无框的决定、替代呈现比较、类别与数量的独立理由、原文证据和必要条件。
2. S47：仅适用框的实际首读与误读；未运行或不适用据实记录，不以不存在的框报通过。
3. 最终保留、删除、移回正文或改写的完整方案及复核；不默认交一套三种框。

## R26 往届获奖论文写法规律与迁移审计

类型：专项审计。覆盖：S81。

目标：以真实获奖范本为依据，核叙事、风格、结构等规律是否可靠，以及本稿该如何借鉴。规则归纳与本稿迁移分别下结论；不是胜负盲审，也不能用S37局部语体对照或R25会议偏好检查替代。

### 输入

已确认会议/年份/文类和获奖名单，作者固定篇目，可读原文，既有分析，本稿及实际研究任务。读取S81全部动作。原始语料和经过核验的总结可复用，不为每个修改批次重新研究全池。

### 执行

1. 核对池、获奖身份、类型与可读范围。固定论文即使没有贡献列表或不符合预想结构也保留，不能换掉反例。
2. 从完整范本重建叙事链和章节职责，随后比较入口、证据安排、语体、术语、图表框及收束。将整体组织与局部句式分别记录。
3. 每条规律须有原文位置、观察范围、支持例、反例/变体和适用条件。数量可描述，不形成配额；获奖不证明某种形式导致获奖。
4. 有既有总结时，由未提出总结的审查者回原文核验；没有时先形成候选再独立核。资料不足时交付已证实部分与缺口，不填造通用规范。
5. 用可靠规律对照本稿相同职责，逐条判迁移、保留差异或不适用。说明读者的哪项判断会改善，给具体候选及证据；正确而有效的不同写法保留。
6. 改法经D01及受影响专项核验；R10核全篇关系，R11核内容逻辑，S37可复用语体证据，各自不重复研究相同语料。停止盲审不等于停止已授权的范本学习；范本分析不进入中立盲审提示。

### 分项回包

语料身份与范围；规律—原文位置—例外—边界—独立核验；本稿位置—作用—迁移/保留理由—具体方案；复用及未查范围。改后检查实际读法和原有长处，不凭“更像获奖稿”或报告数量宣称改善。
