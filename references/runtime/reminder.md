# BestPaper 执行纠偏提醒

先核当前是否仍处于已授权的自动循环。循环已结束或暂停时，停用本提醒并退出，不继续改稿或重启循环。以下只检查正在运行的循环，不构成新授权；作者停止、暂停或改变任务时优先遵从。

先打开真实稿件与当前状态，核对上次提醒后实际发生了什么。优先问：现在这项工作会改变读者对主要工作、贡献或关键证据的哪项判断？若答案只剩“更完整、更可校验、堵住可能追问”，且没有实质风险或明确任务要求，结束这条支线，回主线或交付，不继续包装成审计任务。真实错误、必要条件和重要方法缺口仍按证据处理。

1. 本批让读者更清楚取得什么判断、看到哪项已有价值？改动真的在交付稿中吗？若只在修无关边角，回到主线。
2. 二验是否按专业上下文重建原主张，并核反例没有偷加条件或忽略图注？是否把可选表达优化升级为逻辑错误？改与不改是否有原文、证据或读者任务上的独立依据？作者同意、评审提出和旧裁定不单独作理由。是否又删掉必要解释、堆限定或把论文写成校验报告？
3. 本轮按实际变化选了哪些专项和S项？核验范围与复用依据真实吗？检查点目录不等于代理数量；不重启无关全文审计，也不用总PASS吞掉数学、平凡推理、逻辑或易读性。
4. 独立R19是否看过整批建议及拟搁置项，既防过审也防漏改？从实际变化应有的专项是否漏选，执行/复用是否有当前有效证据，而非只有PASS？已选专项是否实际取得完整动作并留下原文证据？R11模型是否按作者要求指定并核实；R26涉及的获奖规律是否有原文、反例和适用边界？已收到的意见是否都分析？实质裁决是否独立复核，是否可以复用相关专项的同一次核对而不重复派发？未核验和缺证据如实记录，不能伪造通过。
5. 首读者是否提前看过后文或答案？送审输入是否对照独立原稿完整核查？前提污染就重启受影响执行体，不补发纠正后继续。
6. “更准确”的改法是否反而更绕，或让已证贡献变得不显眼？不能仅凭公式/数字未变放行。原问题是否真的消失，修复是否被后续批次覆盖，原长处和必要条件是否仍在？证据足且已授权就完成下一项有价值的写作或验证，不用整理报告代替改稿。
7. 有依据判断实质性收敛时可以停止继续优化，交回完整稿、理由和检查范围并停用提醒。最后润色由人工决定；提醒不能启动新盲审、扩大任务或替作者批准。

仅记录实际偏离及下一步动作。无新问题安静继续，不重复向作者播报提醒内容。循环结束、暂停待作者或转任务时停用；新消息先暂停旧范围，确认继续同一已授权自动循环后才恢复。
